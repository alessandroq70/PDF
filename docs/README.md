# 📎 Unisci PDF — versione online (browser)

Versione dell'app che gira **interamente nel browser** grazie a
[pdf-lib](https://pdf-lib.js.org/): nessun server, nessuna installazione.
I file **non vengono caricati online** — restano sul tuo dispositivo.

È pubblicata gratuitamente con **GitHub Pages**.

## Come si usa

1. Apri il link, clicca sull'area tratteggiata (o trascina i PDF).
2. Riordina i file con le frecce ▲ ▼ se necessario.
3. Clicca **"Unisci e salva"** e scegli dove salvare il PDF unito.

## Pubblicazione (GitHub Pages)

- Repository **pubblico**.
- **Settings → Pages → Deploy from a branch**, cartella **`/docs`**.
- Indirizzo tipo: `https://alessandroq70.github.io/PDF/`

## Note

- Unione **istantanea** e **senza perdita**: le pagine vengono copiate così
  come sono.
- PDF protetti da password possono non essere uniti.
- Esiste anche una versione **da PC** (Flask) nella cartella principale del
  repository, con `run.bat`.
